Joplin

Queria um serviço pra criar notas e sincronizá-las entre meus dispositivos. As notas do iCloud resolveriam isso, mas tanto meu computador do trabalho como o desktop de casa são Windows. Já vinha escrevendo Markdown faz um tempo, escrevendo no meu editor de código normal e enviando as alterações para um repositório Git. O problema dessa abordagem é que às vezes quero escrever no smartphone, e a única opção que vi foi usar o editor de Markdown do GitHub no browser. Às vezes estou no metrô lendo alguma coisa e quero salvar um link ou uma nota sobre o assunto pra olhar mais tarde. Daí a necessidade de usar múltiplos dispositivos.

Procurando um pouco cheguei no Joplin. Aplicativo para várias plataformas e posso criar o meu próprio servidor para promover a sincronia entre os dispositivos. Acho que nem levou uma hora e está tudo configurado. Um docker compose com postgres e o servidor, mais uma regra no nginx e está tudo funcionando corretamente.

version: '3'

services:
    postgres:
        image: postgres:16
        volumes:
            - ./data/postgres:/var/lib/postgresql/data
        restart: unless-stopped
        environment:
            - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
            - POSTGRES_USER=${POSTGRES_USER}
            - POSTGRES_DB=${POSTGRES_DATABASE}
        networks:
            - joplin_network

    joplinsync:
        image: joplin/server:latest
        depends_on:
            - postgres
        ports:
            - "127.0.0.1:22300:22300"
        restart: unless-stopped
        environment:
            - APP_PORT=${APP_PORT}
            - APP_BASE_URL=${APP_BASE_URL}
            - DB_CLIENT=${DB_CLIENT}
            - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
            - POSTGRES_DATABASE=${POSTGRES_DATABASE}
            - POSTGRES_USER=${POSTGRES_USER}
            - POSTGRES_PORT=5432
            - POSTGRES_HOST=postgres
        networks:
            - joplin_network

networks:
    joplin_network:

Login com admin@localhost e pronto. Adicionei regra do nginx, adicionei um novo usuário. Testei a aplicação portátil pra Windows, sucesso na sincronização. Testei no iOS e sucesso também. Tenho uma nova ferramenta pra escrever minhas coisas.

Estou ainda me acostumando com o aplicativo e algumas coisas já me fazem gostar:

  • Corretor ortográfico
  • Organização com tags
  • Metadados como data/hora de criação e modificação.
  • Janela com apenas o editor
