OpenVINO

Hoje embarquei em uma aventura diferente, perguntei pro Chat-GPT como funciona essa coisa de arte generativa. Fui parar no tal stable-diffusion.

https://docs.openvino.ai/2024/notebooks/stable-diffusion-text-to-image-with-output.html

Segue o caminho:

python -m venv openvino
source openvino/Scripts/activate
pip install openvino openvino-dev
pip install diffusers transformers accelerate scipy safetensors
pip install optimum[openvino]

Depois mais um script python bem simples pra rodar a coisa toda passando um prompt e salvar o resultado.

from optimum.intel.openvino import OVStableDiffusionPipeline

model_id = "runwayml/stable-diffusion-v1-5"

pipe = OVStableDiffusionPipeline.from_pretrained(
    model_id,
    export=True,
    compile=True
)

image = pipe("low poly fantasy sword, game asset, studio lighting").images[0]

image.save("result.png")

Pra mim, que nunca mechi com isso tipo de coisa, o resultado foi impressionante.

Fiquei com vontade de testar esse outro negócio aqui pra gerar modelos 3D: https://docs.openvino.ai/2024/notebooks/stable-fast-3d-with-output.html. Mas vai ficar pra outro dia.
